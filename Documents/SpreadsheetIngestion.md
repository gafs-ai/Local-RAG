# Excel・CSVの取り込み（0.26.5）

音声対応より先に、`.xlsx`・`.xlsm`・`.xlsb`・旧形式`.xls`とCSVの取り込みを追加する。設計の出発点は「Excel・CSVのRAG処理を検討」チャット（2026-11-11）。画像化や視覚モデルによる判定を行わず、セル・明示的テーブル・空白・値の特徴から**シート内の領域ごと**に検索用の表現を決める。

自動判定だけで意味を確定できるとは限らないため、シート・セル範囲ごとの手動指定を用意する。判定しにくい領域は位置付きの元テキストとして残す。領域の種類判定と説明作成には、この初期実装ではLLMを使わない。文書カテゴリの分類は既定OFFだが、利用者が有効にした場合は既存のLLM分類工程を使用する。

## 利用者の設定

「設定」→「テキスト処理」→「追加する処理」で「Excel：領域ごとに処理」または「CSV：領域ごとに処理」を選ぶ。新規デフォルトにはExcel用・CSV用のルートを追加する。既存の保存済みルートを自動で書き換えないため、既存利用者は必要なルートを追加する。

| 設定 | 意味・初期値 |
|---|---|
| 領域処理方式 | 自動判定。レコード一覧・数値表・文章・帳票・位置付きテキスト・取り込まないにも固定可能 |
| 見出し行数 | `-1`で自動、`0`で見出しなし、`1`～`20`で各領域の見出し行数を指定 |
| CSV区切り文字 | 自動判別。コンマ・セミコロン・タブ・縦棒を明示可能 |
| 非表示も取り込む | 既定OFF。非表示シート・行・列を検索対象と表示対象に含める場合にON |
| セル数上限 | 既定100,000、設定範囲1～1,000,000。非表示を含む読み取りデータにも上限を適用 |
| シート・範囲ごとの指定 | シート名、A1形式の範囲、処理方式、見出し行数を表形式で追加・削除 |

シート名`*`は全シート。範囲を空欄にするとシート全体の既定を指定する。範囲指定をシート全体の設定より優先し、シート全体の設定では具体的なシート名を`*`より優先する。同じ優先度は上の指定を先に使用する。重なった範囲指定は、意図しない二重処理や欠落を避けるためエラーとする。1シートに適用できる範囲指定は256件まで。

例えば、シート`月報`を自動判定にし、`A4:F30`を数値表、`H4:K20`をレコード一覧に指定できる。指定外のセルも通常の解析対象に残る。特定範囲を「取り込まない」にした場合、その値を隣接領域の文脈として検索索引へ再混入させない。

Excelは`.xlsx`・`.xlsm`・`.xlsb`とExcel 97–2003形式の`.xls`を対象とする。`.xlsx`・`.xlsm`はアプリ内で直接読み、Excelのインストールは不要。`.xlsm`のVBAは無視し、保存済みのセルだけを使用する。`.xls`・`.xlsb`は、このPCにインストールされたWindowsデスクトップ版Microsoft Excelを変換に使用する。暗号化ブックは対象外。CSV用ルートに`.tsv`を明示追加することもできる。

新規デフォルトと新しく追加するExcel用ルートには`.xlsx .xlsm .xlsb .xls`を設定する。保存済みルートの拡張子は自動変更しないため、既存のExcel用ルートでは必要な拡張子を追加して保存する。

### 旧形式.xlsの変換

原本の一時コピーをExcelで読み取り、作業用の`.xlsx`へ変換した後、通常のExcel取り込みと同じ処理へ渡す。原本は変更しない。マクロを実行せず、外部リンクや外部データの更新を要求しない。アプリから明示的な再計算は要求しないが、Excelによる形式変換で表示や保存値が変わる可能性はあるため、重要な数値は原本と照合する。

暗号化されたブック、Excel 4.0（XLM）マクロシートやVBA、外部データクエリを含むブックなど、安全に変換できないものは保留する。パスワード入力や対話ダイアログによる解除は行わない。Microsoft Excel本体はアプリやインストーラに同梱しない。実Officeを使った変換・互換性の検証結果は、パーサーの自動テストとは区別して記録する。

変換は専用プロセスで行い、最大2分で打ち切る。起動前から存在するExcelは終了しない。自分で起動したExcelのPIDと起動時刻を確認して終了し、所有権を確認できない場合は推測で終了しない。変換済みセル情報と読み取り工程の情報を保存するため、Embeddingモデルだけの変更ではExcelによる再変換を省略する。

実装では[Workbooks.Open](https://learn.microsoft.com/en-us/office/vba/api/excel.workbooks.open)の読み取り専用・リンク更新なしを指定する。[AutomationSecurity](https://learn.microsoft.com/en-us/office/vba/api/excel.application.automationsecurity)のマクロ無効化はXLMを対象に含めないため、Excel起動前にも旧形式の構造を検査する。

### .xlsbの変換

`.xlsb`はZIP内にBIFF12のバイナリデータを持つため、直接XMLとして読まず、上記と共通のExcelプロセス管理・時間制限で一時的な`.xlsx`へ変換する。原本のハッシュと専用の読み取り工程IDを保存し、Embeddingだけの変更では変換を再利用する。

Excel起動前にZIP上限、Content TypesのDefault／Override、パーツ間の参照を検査する。XLMマクロシート、外部リンク・データ接続・クエリ・ピボットキャッシュ・埋め込みオブジェクト等を含むブックは保留する。VBAの存在だけでは拒否せず、Excelのマクロ強制無効化とイベント無効化を使用する。通常のハイパーリンクは取得・更新しない。BIFF12の意味を網羅的に解析する検査ではない。

`.xlsm`はExcelを起動せずXMLのセルデータを読むため、VBAや外部接続を実行しない。マクロが実行されると生成される値を新たに作る処理は行わない。

## 読み取りと保存

`.xlsx`（旧`.xls`から変換したものを含む）はZIP内のSpreadsheetMLを読み、ワークブック、シート、共有文字列・インライン文字列、数値・日付・真偽値・エラー、数式、保存済み計算結果、書式情報、太字、結合範囲、Excelテーブル定義、非表示情報を取得する。ZIPをディスクへ展開しない。外部リンク・データ接続・マクロを実行しない。

SpreadsheetML読み取り時には数式を**再計算しない**。数式と保存済み値を区別して保持し、キャッシュがない場合も式を捨てない。旧`.xls`については変換後の保存値を扱う。表示書式の完全再現は行わず、数値や日付の原値・取得できた書式を保持する。日付は1900／1904日付方式を考慮する。Excelの架空の1900-02-29は勝手に別日へ補正しない。

CSVは既存の文字コード判別・明示指定を再利用する。引用符内の改行、区切り文字、二重引用符のエスケープを解釈する。物理的な1行を1レコードとはみなさない。区切り文字の候補が同程度なら注意を残し、利用者が明示指定できる。見出しが必ず存在するとは仮定しない。

保存スナップショットはファイル単位で次を保持する。

- データソース名・文書ID・原本パス・原本ハッシュ・工程の処理方法情報。
- シート名、各セルの行・列・文字表現・型・原値・数式・取得できた書式、非表示状態。
- 結合範囲、テーブル名・範囲・見出し行数、読み取り上の注意。
- 各領域の種類・セル範囲・返却用本文・検索用表現。

原本全体の秘匿検査に必要なため、通常は検索しない非表示セルもローカルの読み取りスナップショットと検査用テキストに保持する。非表示を含めない設定では、検索用の領域・文脈から除外し、その範囲の取得も拒否する。

## 領域を決める順序

1. 手動範囲指定を適用する。
2. 残りのセルにExcelの明示的テーブル範囲を適用する。
3. 残りを空白行・空白列で分け、孤立した文章・タイトル・注記と複数列の表を分ける。
4. 見出し候補、行の幅の安定性、数値比率、文章の長さ、ラベル表記で処理方式を判定する。
5. 確信できる条件に該当しなければ、位置付きテキストとして残す。

空白のない隣接表、複雑な入れ子表、印刷配置だけで関係を示す帳票の完全な自動認識は保証しない。罫線・色・結合だけから意味を推定しない。表の直前2行・直後1行に単独の記載があれば文脈として付けるが、それ以外の遠い注記まで自動関連付けするものではない。

結合された見出しは、対応する列の**ラベル**としてだけ展開する。元の空セルへ値を生成して保存しない。数値の先頭行を安易に見出しとして捨てず、見出ししかない領域も位置付きテキストとして残す。

## 領域別の検索用表現

| 種類 | 埋め込み | 返却・保持 |
|---|---|---|
| レコード一覧 | 1レコードごとにシート・範囲・表名・文脈・列名と値を組み合わせる | 当該レコードと元のセル座標。長い場合は同じ領域IDのままEmbedding上限で分割 |
| 数値表 | 表の文脈、列見出し、最大24件の行見出し、データ行数、保存値の注意をコードで組み立てた説明 | 元の表本文、すべての読み取ったセル値・式。数値本体を全行ベクトル化しない |
| 文章 | 行順・列順のセル本文を段落として扱うMarkdown表現。単独の短い太字は見出しとして表現 | セル対応を維持。LLMによる文章の生成・書き換えは行わない |
| 帳票 | 行内の「項目名：値」の対応 | 項目・値それぞれのセル座標 |
| 判定保留／位置付きテキスト | セル座標と値の保守的な表現 | 読み取ったセル値を保持 |

文章型も含め、領域の検索用表現は既存のモデル入力上限制御で機械的に分割する。Excel・CSV専用経路では、通常文書用の分類・整形・LLMチャンク結合・LLM親説明生成は行わない。現在の設定で利用しない項目は画面に表示しない。

数値表の説明は「どの表に求める内容がありそうか」を検索するためのもの。特定IDの完全一致、任意条件の抽出、SQL、集計、前年比計算はこの版では実装しない。類似検索で上位に出た行だけを全データとみなして集計してはならない。

## 検索と範囲取得

範囲に対する「取り込まない」は検索索引からの除外であり、秘匿指定ではない。一部の領域を除外しても、その文書の全文・範囲取得では元の可視セルを取得できる。非開示が必要な文書には共通の秘匿設定を使用する。ルート全体を省略して索引へ公開していない文書は取得できない。

検索では既存のベクトル検索・構造検索を利用し、結果にシート名とセル範囲を付ける。原則として元のレコード・領域本文を返し、8,000文字を超える領域は短い概要と位置へ縮小する。大きな数値表の全体を検索結果へ無制限に展開しない。

MCPの既存の`fetch`に、任意の`sheet`と`range`を追加する。両方を指定した場合だけ範囲取得になる。文書IDは`search`が返すUUIDを使い、領域IDを渡さない。

```json
{
  "id": "検索結果の文書ID",
  "sheet": "月報",
  "range": "A4:F20"
}
```

範囲はA1形式で、1回あたり矩形10,000セル以下・返却100,000文字以下。範囲を小分けにして必要な元データを取得できる。CSVのシート名も検索結果に従う。格納された非空セルを座標付きで返し、省略された座標は空欄であることを明記する。式と保存値を返すが再計算は行わない。範囲を省略した`fetch(id)`は読み取った文書全体の取得として残す。

どちらの取得でも原本ハッシュと現行設定を確認し、元ファイルが更新済みなら古いスナップショットを返さない。秘匿機能が有効なら、ブック全体と返却内容を検査する。先頭・末尾のパターン検査は各シートの先頭・末尾の「値のある行」にも適用し、非表示の行も検査する。セル1個を1行と数えるのではない。範囲内に秘匿情報がなくても、ブック全体の検査で非開示になれば本文・セル値を返さず、文書ID・判定・原本パスだけを返す。

## 再処理・負荷・制限

読み取り、領域構築、埋め込みを工程情報で区別する。処理方式・見出し・範囲指定の変更は既存のセルデータから領域を再構築できる。Embeddingモデルだけを変更した場合は領域・説明を再利用し、新モデルの枠で分割して埋め込みを更新する。文書更新時は原本を再読み取りする。既存の監視優先順位、失敗時の再試行規則、推論呼び出し間の検索優先を維持する。

ファイルは64MiB以下。ExcelはZIP展開後総計128MiB以下、XML部品32MiB以下、ZIPエントリ10,000個以下。セル数と、座標・数式を含む抽出文字数にも既存の文書上限を適用する。上限を超えたデータを黙って途中で切って成功扱いにはしない。取り込み履歴の理由を確認して原本を分けるか、必要な設定を見直す。

ルート全体を「取り込まない」にして範囲指定がない場合は、内容の解析を行わず原本ハッシュだけを確認して省略する。範囲指定がある場合は、その範囲だけを復帰できるよう元のセル解析を行い、領域ごとに指定を適用する。

領域解析は実在するセル座標の索引を用い、使用範囲の端まで巨大な空配列を生成しない。大きなレコード一覧ではLLMの呼び出しをなくしても、全レコードのEmbedding・DB保存に時間を要する。

図、画像、グラフ、コメント、印刷ページ構造の完全復元、ピボット集計の実行、外部データ更新は行わない。自動判定・読み順・日付／数値の表示を含め、重要な内容はExcelやCSV原本と照合する。

## 検証方針

複数表・左右の表・文章混在・見出しなし・複数行／結合見出し・数値表・帳票・非表示データ・式とキャッシュ・多言語CSV・引用符内改行・再処理・秘匿検査・MCP範囲取得を自動テストする。実務文書での分類精度、表の発見、個別レコードの発見、取り込み時間は自動テストとは別に評価する。音声対応はこの版の対象外。
