# Local RAG バージョン0.26.3

Word文書の取り込みを追加し、取り込み中の検索待ちと監視停止の問題を改善しました。

- `.docx`・`.docm`をMarkdownへ直接変換し、見出し・本文・表・脚注等を既存の親子チャンク処理へ接続します。
- 旧形式`.doc`はインストール済みMicrosoft Wordを専用プロセスで使い、元文書のコピーから変換します。
- 太字の見出し推定、手動改行の結合、ローカルLLMによる構造補正を個別に設定できます。本文を生成・削除するLLM修正は許可しません。
- ヘッダー・フッターを本文から除きつつ、機密ラベルと秘匿検査用の抽出本文を保持します。検索・全文取得とも既存の秘匿検査を適用します。
- 変換と補正の処理情報・途中経過を保存し、モデルや設定が変わったときは必要な工程だけを再実行します。
- 11月10日の修正では、内部タイムアウトで監視全体が停止する問題に対応しました。履歴・一覧更新の一時エラーを取り込み本体から切り離し、監視が一時エラーで終了した場合は自動復帰します。[詳細](MonitoringRecovery-2026-11-10.md)。
- 取り込み中の検索・全文取得を優先します。文書全体の完了を待たず、実行中のAI呼び出しが終了した時点で取得を実行し、その後取り込みを再開します。未完成文書は返さず、待機時間と取得の実処理時間を診断ログへ記録します。

既存利用者は「設定」→「テキスト処理」から「Word文書：Markdownへ変換」の処理を追加して保存してください。保存済みの処理設定や対象拡張子は自動的に上書きしません。新規設定にはWord用の処理を用意しています。

詳しい使い方・制約は[Word取り込み](WordIngestion.md)を参照してください。画像OCR、PDF、音声は未対応です。暗号化文書、数式、埋め込み文書等は保留します。変換結果・LLM補正は元の見た目や意図を完全には再現しません。

検証結果は[Word取り込み検証](WordValidation-2026-11-09.md)に記載します。今回はComputer Useによる画面試験を行っていません。


## 更新方法

Local RAGを「アプリを完全終了」で終了してから、`LocalRAG-0.26.3-win-x64.msi`を実行してください。既存の設定・索引・元文書・モデルを維持します。.NETの別途インストールは不要です。Word対応は新規設定では有効ですが、保存済み設定には上記の手順で処理を追加してください。検索優先制御の変更による索引の再構築は不要です。

## 検証と制約

公開前の最終回帰テストは465件成功・失敗0・1件スキップでした。スキップは任意のLemonade実プロセス起動・終了試験です。Word処理、実SurrealDB、検索優先制御、HTTP MCP、キャンセル・再開を含めて検証しています。

本PCで更新インストール・設定保持・起動を確認し、利用者にも割り込み動作を確認いただきました。Gemma-3-4b-it-mm-NPUとnomic-embed-text-v2-moe-GGUFによるWord取り込み、HTTP／stdioの検索・全文取得を検証しています。通常の取り込み中のプラグイン検索は約11.9秒、全文取得は約0.5秒で成功し、検索後の取り込み完了も確認しました。条件を固定した性能比較ではなく、推論1回や検索自体が長ければ100秒のMCP期限を超える可能性は残ります。[検索優先の検証記録](RetrievalPriority-2026-11-10.md)。

LLMによる秘匿判定は試験的で既定OFFです。MSIは未署名で、別のクリーンなWindows 11 PCでの初回導入は未検証です。ChatGPTのブラウザ版接続は別途対応が必要です。既存のローカルプラグインからの接続方式は変更していません。
