# Local RAG 0.26.8

アプリの更新通知を追加しました。新しい正式版が見つかると、管理画面の下部とWindows通知で更新を案内します。

- 起動時に確認履歴を読み込み、前回から24時間以上経過していればGitHubの正式リリースを確認。常駐中も24時間ごとに確認。
- 新しい版があると管理画面下部に案内を表示し、Windowsのポップアップ通知を要求。同じ版の通知履歴は再起動後も保持。
- 「更新ページを開く」でインストーラと変更内容を確認。
- 「設定」に自動確認のON/OFFと「今すぐ更新を確認」を追加。
- 更新確認は取り込み・検索から独立し、ネットワーク不通でも文書処理を継続。

自動インストールは行いません。詳細は[更新通知](UpdateNotifications.md)を参照してください。

0.26.7以前には更新通知機能がありません。0.26.8への最初の更新は、従来どおりMSIで行う必要があります。

更新前に「アプリを完全終了」でLocal RAGを終了し、`LocalRAG-0.26.8-win-x64.msi`を実行してください。設定・索引・元文書は保持されます。

Windowsの通知設定や応答不可モードによってポップアップが表示されない場合でも、管理画面下部から更新ページを開けます。通知確認用の一時アプリ・架空の更新情報は製品に含みません。

検証状況は[更新通知の検証記録](UpdateNotificationsValidation-2026-11-13.md)、[手動確認用MSIのインストール記録](DistributionValidation-0.26.8-2026-11-13.md)、[公開前検証](ReleaseValidation-0.26.8-2026-11-13.md)を参照してください。
