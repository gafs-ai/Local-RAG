# 複数AI接続先の開発検証（0.26.7）

実施日：2026-11-12。ブランチ：dev。開発版であり、リリース・更新インストールは未実施。

## 実装

- Lemonade / OpenVINO Model Server / LM Studioの複数接続先と、言語モデル・Embeddingモデルの個別選択。
- HTTP/HTTPSの外部接続、BearerキーのWindows DPAPI保存。接続先の種類・完全なベースURL・IDに紐付ける。
- 接続先ごとのローカル自動起動と終了連動。外部接続、既存プロセス、認証エラー、使用中ポートでは新しいプロセスを起動しない。
- LM Studioの実行時コンテキスト・モデルロードAPI、OVMS等の明示的な入力上限、JSON要求切替。
- 従来設定の互換、SchemaVersion=3の保存、接続先に応じた再処理、APIキー変更後の失敗再試行。
- 管理画面、F1ヘルプ、外部依存のライセンス通知。

## 試験結果

`dotnet build LocalRAG.slnx -c Release --no-restore`：成功、警告0・エラー0。生成EXEのファイル版は0.26.7.0。

| 段階 | 結果 | 記録（リポジトリ内・非配布） |
| --- | --- | --- |
| 全体回帰 | 737成功・3失敗・1スキップ、16分48秒 | `tests/LocalRag.Tests/TestResults/ai-connections-full.trx` |
| 修正・追加後の試験 | 190成功・失敗0・1スキップ、17秒 | `tests/LocalRag.Tests/TestResults/ai-connections-final-targeted.trx` |

最初の失敗3件は、フィードバック添付の試験で0.26.6を固定していたため、アプリ版0.26.7との一致検査に失敗したもの。試験の添付版に`ProductInfo.Version`を使用して解消した。製品側の版一致検査は維持した。

全体試験の後に追加した試験も含め、テストIDを照合して最新結果を採用すると、**747成功・1スキップ・未解決の失敗0**。最終変更後に全体を一括で再実行した件数ではなく、全体回帰と修正・追加箇所の再実行を合わせた結果である。スキップは、インストール済みLemonadeを隔離構成で起動する明示的オプトイン試験。通常利用のLemonade・索引は操作していない。

確認した内容：

- 2つの実HTTP待受を試験用に起動し、チャット／Embeddingの本文・モデル名・認証キーが指定先へ分離されること。
- 3種類ともHTTPリダイレクトに追従せず、転送先へ認証キーを送信しないこと。
- LM Studioの模擬APIによるロード済み・未ロードのモデル情報、理論上限を使わない入力予算、逆プロキシのURL接頭辞、401等でのフォールバック禁止。
- JSON出力切替、不完全な生成の拒否、不正なベクトル・件数・位置の拒否。
- DPAPI保存、キーの別URL／種類／IDへの流用禁止、設定JSONへキーが含まれないこと。
- 実SurrealDBの専用データによる、設定形式移行時の再処理なし、Embedding接続先変更時のLLM結果再利用、旧ベクトル空間の検索除外。
- 代替ランタイムによる起動の一回性、接続先ごとの終了設定、既存・外部・削除済み接続先の所有権、認証エラー・使用中ポートの扱い。
- OVMS用環境変数を親アプリへ反映しないこと、外部推論の速度をローカル機材へ対応付けて送信しないこと。
- 設定画面の編集項目にヘルプがあること、ライセンス原文／通知がビルドに含まれること。ライセンス棚卸しは34 NuGet依存と一致。

## 未検証と配布前の確認

Computer Useと画面操作は実施していない。OVMS・LM StudioはPATHと標準配置先で確認できず、製品の実サーバーを起動した試験・実モデルによる取り込み／検索は未実施。模擬API・実HTTP通信の成功は、各製品・モデル・機材での動作保証を意味しない。

配布前に次を確認する：

1. 実際のOVMSとLM Studioの版・モデルで、入力上限・JSON出力・Embeddingを確認。
2. Intel NPUとNVIDIA GPUなど、対象デバイスで取り込み・検索・検索の割り込みを確認。
3. 未起動／起動済み／起動待ち中終了／設定変更時の、実CLIとプロセスによる連鎖起動終了を確認。
4. 画面で接続先追加・編集・削除、モデル選択、APIキー保存／削除、ヘルプを確認。
5. 利用統計の配布版設定とインストーラを準備し、更新保持を確認。

LM Studioの終了連動はHTTPサーバーを止め、共有のGUI・デーモンを残す仕様。外部サーバーの起動終了はサーバー側で管理する。詳細は[AiConnections.md](AiConnections.md)と[設定ガイド](SettingsGuide.md)を参照。
