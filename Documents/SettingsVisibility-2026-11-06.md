# テキスト処理設定の条件付き表示

選択した設定で利用される入力項目だけを表示する。非表示の値とユーザープロンプトは保持する。既存の取り込みロジックと設定ファイルの意味は変更しない。

| 条件 | 表示する項目 |
|---|---|
| コード入力 | コード説明プロンプト、分類、文字コード。通常テキストの処理項目は非表示 |
| 分類ON | 分類プロンプト、有効カテゴリの選択 |
| 分類OFF | 既定カテゴリに対応する処理行だけ |
| 通常テキスト、LLM結合 | 結合プロンプトとカテゴリ別プロンプト |
| 通常テキスト、機械的結合 | プロンプトではなく、結合する／しない |
| 通常テキスト、段落単位 | 結合のプロンプト・切替は非表示 |
| Markdownかつ親を文書構造で作る | Markdown親の最小・最大文字数 |
| LLMで親をまとめる | 親のまとめプロンプト |
| 親あり | 親の埋め込み方式 |
| 親あり、長い親の説明生成ON | 親の説明プロンプト |
| 共通動作を継承 | 実際に継承している共通スイッチ |

分類結果が割れたときにも既定カテゴリを使うため、既定カテゴリは分類ONでも表示する。Markdownの見出しレベルは子の結合とLLM親の処理境界にも影響するため、親なしでも有効。混在拡張子は、いずれかの対象で有効な項目を表示する。コードのチャンク上限は説明の埋め込み分割にも使われる。

自動テスト9件で、明示的な各親モード、コード9言語、継承時のMarkdown例外、混在拡張子、共通設定の切替を確認。ビルドは警告0・エラー0。

Computer Useでは`.local/settings-visibility-ui/data`の専用設定を使い、C#で通常テキスト設定が非表示になること、Markdownの文書構造→LLM→親なしの切替、txtではMarkdown長さ設定がないこと、保存成功を確認した。非表示になったMarkdownの最小500・最大4000と親埋め込み方式が保存後も保持されていることをファイルでも確認。通常設定・取り込みデータは変更していない。検証用アプリは通常の終了ボタンで終了。
