# ロゴの組み込みと検証（2026-11-05）

承認済みの青いフォルダと白い虫眼鏡のPNGを、Windowsアプリとローカルプラグインに組み込みました。原画は `Assets/Brand/local-rag-logo.png` に保存しています。

## 適用先

- Windows実行ファイル、ウィンドウ、タスクバー：複数サイズのICO。
- タスクトレイ：同じICOから読み込む専用Icon。終了時に破棄します。
- 管理画面：タイトルの左側に透過PNGを表示します。
- プラグイン：Desktop互換形式の `interface` とPortable形式の `extensions.com.openai.interface` に、`logo` と `composerIcon` を指定します。画像をZIPに同梱します。

`scripts/Build-BrandAssets.ps1` で透過余白を調整し、縦横比を維持してPNGとICOを再生成できます。

## 実施した検証

- 代替出力先と通常のReleaseフォルダでビルド成功。警告0、エラー0。
- ICOの全9フレーム（16～256px）の画像データと寸法を検証。
- WPFアセンブリ内にICO・PNGの両リソースが含まれることを確認。
- 実行ファイルからアイコンを抽出し、ロゴが埋め込まれていることを画像で確認。
- Desktop/Portableプラグイン両方を生成。ZIP内の画像、manifestからの参照、正方形の寸法、透過背景を確認。
- パッケージ作成で発見したUTF.Unknown 2.7.0のライセンス同梱漏れを修正。NuGetに含まれるREADMEのGPL-2.0-or-later代替条件の記載を確認し、README・GPLv3本文・出典を同梱。
- 既存プラグインの診断：rc.5、有効、`search` / `fetch` を認識、ToolsErrorなし。
- Computer Useは使用していません。実際のウィンドウ・通知領域・ChatGPTのアイコン表示は未検証です。

通常のアプリは `src/LocalRag.Desktop/bin/Release/net10.0-windows/LocalRag.Desktop.exe` へ配置済みです。

今回の検証用パッケージ（正式リリースではありません）：

- アプリ：`artifacts/0.0.0-rc.6-20261105-202700/LocalRAG-0.0.0-rc.6-win-x64.zip`

Desktopプラグインは既存の `.local/manager-validation/data` に接続します。このPC専用設定を含むため、他の利用者への配布用ではありません。

## インストール済みプラグインへの反映は保留

登録済みマーケットプレイスのソース `.local/plugin-business-test/local-rag` は更新しました。更新前のソースは `.local/branding-marketplace-backup` に保存しています。

公式CLIによる更新は `failed to back up plugin cache entry: アクセスが拒否されました` で停止しました。使用中のプロセスによるロックの可能性がありますが、確定はしていません。インストール済みキャッシュを直接編集せず、既存rc.5が有効なことを確認しました。

ChatGPTとCodexを終了した後、PowerShellで次を実行し、アプリを再起動してください。

```powershell

```

`codex` がPATHにない場合は、インストール済みCodex CLIの実行ファイルをフルパスで指定してください。配置先はインストール環境やバージョンによって異なります。

更新後にrc.6の認識とホスト画面上のロゴ表示を確認する必要があります。ChatGPTのクラウド側にある別の同名プラグインの公開・更新は行っていません。
