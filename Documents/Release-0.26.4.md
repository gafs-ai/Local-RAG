# Local RAG バージョン0.26.4

PDFの取り込みを追加しました。現在はこのPCでの更新・動作確認用で、GitHubでの公開リリースは未実施です。

- 1/4・2/4・3/4付近のページからコードでサンプリングし、必要なら追加調査します。文字主体と判定したPDFをMarkdownに変換し、画像主体・判定不能な文書は理由付きで省略します。
- 反復するヘッダー・フッター、ページ番号を除去し、本文との間隔が大きい内側のフッターにも対応します。機密ラベルと検査用の除去前文字は保持します。
- Wordと共通の構造補正・分類・親子チャンク・埋め込み・検索へ接続します。元PDFのページ番号を検索用本文と章名に保持します。
- PDFの自動判定、判定を省略した文字抽出、取り込み対象外を設定できます。
- 同じ原本・変換設定では変換を再利用します。LLMの不正な補正結果は原文保持へ切り替え、Embeddingモデルだけの変更では補正結果を再利用します。
- 設定ヘルプとPDFガイド、PdfPigのライセンス・第三者通知を同梱します。検索画面とMCPに抽出情報の限界を表示します。

## 更新後の設定

既存の設定・文書・索引は初期化しません。既存設定にはPDF用の処理を自動追加しないため、「設定」→「テキスト処理」→「追加する処理」で「PDF文書：判定してMarkdownへ変換」を追加し、保存してください。新規設定にはPDF用を含みます。

## 制約と検証

Word・PDFの検索は内容の概要と原本の発見を目的とします。画像・図表・配置による意味は欠落し得ます。OCR、図の理解、表の完全な構造再現は行いません。重要な内容は原本で確認してください。自動判定が誤る場合は、設定から抽出可能な文字の取り込みを試せます。

自動試験と公開PDFでの変換を確認していますが、多言語・実務文書全般での検索品質や画面操作の検証を完了したものではありません。[PDF仕様](PdfIngestion.md)と[検証記録](PdfValidation-2026-11-10.md)を参照してください。
