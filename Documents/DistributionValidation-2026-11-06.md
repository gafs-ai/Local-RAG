# 配布準備の検証（2026-11-06）

今回の範囲は、利用者向けガイド、設定ヘルプ、配布用プラグイン説明、Windows用インストーラです。正式0.0.0の公開は行っていません。

## 成果物

- [クイックスタート](QuickStart.md)：最小限の導入・設定、RAM／NPUによるモデル選択の目安、開発用モデル、Embedding変更時の再構築、環境フィードバック。
- アプリ内ヘルプ38項目：メイン・処理設定画面から表示、項目検索、F1、ツールチップ。ヘルプ本文は埋め込みリソースでオフライン利用可能。
- プラグインのdescription、longDescription、homepage、README、スキル：本体が必要な旨とGitHubのガイドURL。
- .NET 10同梱win-x64 ZIP／日本語MSI。ユーザー単位のインストール、スタートメニュー、更新と削除。WiX UIのライセンスと対応ソースをMSIに同梱。
- 環境・モデルのフィードバック用GitHub Issueフォーム。

## 確認したこと

| 検証 | 結果 |
| --- | --- |
| 全体回帰 | 395件成功、1件スキップ。実Lemonadeの起動試験は明示的に無効のためスキップ |
| 設定ヘルプ | 項目ID・コントロール対応の重複なし、編集可能な名前付き設定項目を網羅、リンク形式を検証（追加3件） |
| ビルド | Desktop／MCPのwin-x64自己完結型publish成功 |
| マニフェスト等 | プラグインJSON、ヘルプJSON、スキルYAML、IssueフォームYAMLを解析して確認 |
| プラグイン | 実行ファイルを直接起動し、MCP initialize、tools/list、アプリ停止時のretrieval_unavailableを確認。search/fetchを認識 |
| ホスト診断 | 新しい配布候補の版を読み取り、search/fetchとtoolsErrorなしを確認。登録・インストール操作は行っていない |
| Computer Use | アプリのヘルプ表示、Markdownでの項目検索、データソース入力欄のF1、処理設定からの対応ヘルプを確認。設定保存はせず終了 |
| MSI画面 | 日本語の導入画面、GPLライセンス表示、既定のインストール先を確認。通常版の導入はキャンセルし、変更なしの終了画面を確認 |
| MSI自動試験 | 専用UpgradeCodeの試験パッケージをカスタムフォルダへ導入→更新→削除。各終了コード0。更新後の製品登録1件、ショートカットの参照先、不要になった旧ファイルの削除を確認 |
| データ保持 | 削除後も別フォルダの試験用データと、画面検証で使ったsettings.jsonのハッシュが不変 |

インストール先を記録しない初期実装では、カスタムフォルダを使用した更新時に旧ファイルが残った。HKCUにインストール先を保存し、更新・削除の開始時に参照するよう修正した。修正後は更新と削除に `INSTALLFOLDER` を渡さず、同じカスタムフォルダが使われることを再検証した。

Computer UseはWindows Installerへの初回接続で承認待ちタイムアウトになったが、再接続で復旧した。MSIでは画面切り替えごとにウィンドウIDが変わるため再取得した。通常運用中のアプリとDBは試験対象にしていない。
