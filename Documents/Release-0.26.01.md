# Local RAG バージョン0.26.01

Windows 11 x64向けのテキスト・Markdown・ソースコード検索アプリです。導入は[クイックスタート](QuickStart.md)、設定は[設定ガイド](SettingsGuide.md)を参照してください。

## 主な機能

- フォルダの定期監視、優先度キュー、更新除外期間、ignore指定。
- 小さいコンテキストに対応する分類・整形・親子チャンク処理。ソースコードは説明文を埋め込み、説明とコードを返却。
- 親・子の類似度を使う構造検索と、設定変更に応じた工程単位の再処理。
- MCPの検索・文書全文取得と、範囲を指定できる秘匿パターン検査。
- データソース名による文書キーの分離。自動生成名は `Local-{Windowsユーザー名}-{ランダム4文字}`。
- アプリ内の設定ヘルプ・依存ソフトウェアのライセンス閲覧、.NET同梱のMSIとZIP。

## 検証と制約

この版の自動回帰テストは397件成功、1件スキップです。スキップは実インストール済みLemonadeを起動する任意のライフサイクル試験です。実DBの統合試験を含みます。新しいライセンス一覧と原文の組み込み、依存パッケージとの一致も確認しました。

Word・PDF・音声は未対応です。LLMによる秘匿判定は試験的で既定OFFです。モデルの分類・説明生成には誤りがあり得ます。ChatGPTのブラウザ版接続は別途対応が必要です。

MSIは未署名です。.NET未導入のクリーンな別PCでの初回導入は未検証です。この版のライセンス画面はビルドとリソース読み取りテストで確認し、画面操作による再検証は行っていません。
