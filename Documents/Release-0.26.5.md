# Local RAG バージョン0.26.5

音声対応より先にExcel（.xlsx・.xlsm・.xlsb・.xls）とCSVの取り込みを追加しました。利用者が実際のExcel・CSVファイルで正常動作を確認したため、0.26.5としてリリースします。初版の[更新確認](DistributionValidation-0.26.5-2026-11-11.md)と追加形式の[検証記録](ExcelFormatsValidation-2026-11-12.md)を参照してください。

- .xlsxはExcelを起動せず、セル・型・座標・結合・テーブル定義・数式の保存結果を直接読み取ります。Excelのインストールも不要です。
- .xlsmも直接読み取り、VBAは無視します。.xlsbはインストール済みExcelで一時的な.xlsxへ変換します。変換時はVBAを無効化し、XLMマクロシートや外部接続等を持つ.xlsbは保留します。
- Excel 97–2003形式の.xlsは、導入済みのWindowsデスクトップ版Microsoft Excelで一時コピーを.xlsxへ変換し、同じ取り込み処理へ渡します。原本は変更しません。明示的な再計算・マクロ実行・外部データ更新は要求しません。
- シート内の領域ごとにレコード一覧、数値表、文章、帳票、位置付きテキストへ振り分けます。シート名・範囲単位で手動指定できます。
- レコードは列名付きで検索対象にします。数値表は見出し・分類軸などの説明を埋め込み、元の値は別途保持します。文章・帳票もセル位置を保持してテキスト化します。
- 検索結果にシート名・セル範囲を追加します。MCPの既存`fetch`で`sheet`と`range`を指定すると、最大10,000セル・100,000文字の範囲を取得できます。指定を省けば従来の文書全体取得です。
- 取得前に原本の鮮度と秘匿性を検査します。非表示セルも秘匿検査用には保持しますが、既定では検索・取得に表示しません。先頭・末尾パターンの検査は各シートに適用します。
- CSVは引用符内改行とエスケープを解釈し、既存の文字コード判別と区切り文字設定を利用します。

既存設定には処理を自動追加しません。「設定」→「テキスト処理」でExcel用／CSV用を追加してください。新規設定には両方を含み、Excel用の拡張子は.xlsx・.xlsm・.xlsb・.xlsです。保存済みのExcel用設定は維持するため、追加形式を取り込む場合は必要な拡張子を追加してください。索引全体の初期化は不要です。

暗号化ブック、画像・図形・グラフの理解、数式再計算、マクロ実行、外部リンク更新、任意の集計は対象外です。旧.xlsの変換では、XLM・VBAマクロや外部データクエリを含むブックなどを保留します。数式の保存値は最新とは限らず、Excelの形式変換で表示や保存値が変わる可能性もあるため、重要な数値は原本と照合してください。自動の領域・見出し判定はヒューリスティックで、複雑なレイアウトでは位置付きテキストや手動指定で補います。類似検索の上位行だけを使って表全体の集計をしないでください。

Microsoft Excelは配布物に同梱しません。実Officeによる旧.xlsの変換・互換性の検証結果は、パーサーの自動テスト結果とは区別します。

詳しい設計と設定は[Excel・CSV取り込み](SpreadsheetIngestion.md)を参照してください。

公開前の全体回帰試験は[検証記録](ReleaseValidation-0.26.5-2026-11-12.md)を参照してください。
