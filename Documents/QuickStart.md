# Local RAG クイックスタート（バージョン0.26.4）

Windows 11（64ビット）で、PC内のPDF・Word・テキスト・Markdown・ソースコードを検索できるようにします。音声は未対応です。PDFは文字主体の文書を自動判定して取り込みます。旧形式の.docだけはMicrosoft Wordが必要です。

## 1. インストールする

1. [Lemonade Server](https://lemonade-server.ai/docs/guide/install/windows/)をインストールします。
2. Local RAG 0.26.4のMSIを開き、画面の案内に従ってインストールします。現在は更新検証用です。公開済みの配布物は[リリース一覧](https://github.com/gafs-ai/Local-RAG/releases)で確認できます。

Local RAGのインストーラには.NETランタイムが含まれます。DBは初回起動時に自動で導入します。初回はインターネット接続が必要です。

## 2. Lemonadeでモデルをダウンロードする

Lemonadeのモデル一覧から、**言語モデルとEmbeddingモデルを1つずつ**選んでダウンロードします。専用ビデオカードがないPCでは、次を出発点にしてください。

| PCの環境 | 言語モデルを選ぶ目印 | Embeddingモデルを選ぶ目印 |
| --- | --- | --- |
| メモリ32GB、対応NPUが40 TOPS以上 | Gemma・4B・NPU対応 | nomic-embed-text・v2 |
| メモリ32GB、NPUなし／NPUを使わない | Gemma・4B | nomic-embed-text・v2 |
| メモリ16GB | Gemma・2B | nomic-embed-text・v2 |

NPUはLemonadeが対応する機種・ドライバーである必要があります。40 TOPSという数値だけでは利用可否は決まりません。対応モデルが表示されない場合は、NPUを使わないモデルを選んでください。これは動作保証表ではなく、試行の目安です。

モデルのダウンロードサイズは、モデル本体が使うメモリの目安です。実行にはそれ以上のメモリが必要なので、Windowsやほかのアプリの分も残して選びます。目安の詳細は[Lemonadeの案内](https://lemonade-server.ai/docs/guide/faq/#3-how-do-i-know-what-size-model-will-work-with-my-setup)を参照してください。

モデルは変更して構いません。開発で使用しているのは次の組み合わせです。

- 言語モデル：`Gemma-3-4b-it-mm-NPU`
- Embeddingモデル：`nomic-embed-text-v2-moe-GGUF`

**Embeddingモデルを途中で変更すると、検索用の埋め込みデータの再構築が必要です。**

## 3. Local RAGを設定する

1. モデルのダウンロード完了後、スタートメニューから **Local RAG** を起動します。
2. 「設定」で、**監視フォルダ**を「追加」します。
3. **言語モデル**と**Embeddingモデル**に、ダウンロードしたモデルを選びます。一覧にない場合は「接続状態」→「接続確認・モデル一覧更新」を押します。
4. 「設定を保存」を押し、「取り込み」で「監視再開」または「今すぐ実行」を押します。

ほかの設定は、そのままで始められます。初期設定では、更新から10分以内のファイルは取り込みを待ちます。

## 4. 検索する

「取り込み」で処理が完了したら、「検索」に具体的な質問を入力します。例：`有給休暇を申請するときの手続き`。

ChatGPTから使う場合は、Local RAG本体を起動したままプラグインを追加します。**プラグイン単独では動作しません。** 接続方法は[ChatGPTとの接続手順](MCPConnection.md)を参照してください。

画面の「×」で閉じても処理は続きます。完全に止める場合は「アプリを完全終了」を選びます。設定で迷ったときは、アプリの「ヘルプ」または各項目で **F1** を押してください。

## 動作状況を教えてください

環境とモデルの試行データを収集中です。[フィードバック](https://github.com/gafs-ai/Local-RAG/issues/new?template=environment-feedback.yml)に、**CPUモデル、RAM容量、専用GPU（あれば）、使用モデル、動作状況（動かない・遅い・快適など）**をお知らせください。文書の本文や秘密情報は記載しないでください。

## 以前の版から更新した場合

Wordを取り込むには「設定」→「テキスト処理」で「追加する処理」から「Word文書：Markdownへ変換」を選び、追加して保存します。新規インストールでは設定済みです。詳しくは[Word取り込み](WordIngestion.md)を参照してください。

PDF用の設定も新規インストールでは用意されています。更新の場合は「設定」→「テキスト処理」から「PDF文書：判定してMarkdownへ変換」を追加して保存します。画像や図表の情報は欠落する場合があるため、重要な内容は原本で確認してください。[PDF取り込みの説明](PdfIngestion.md)。
